## 1️⃣ 事件基类定义

### 📡 WIFI_EVENTS（系统/网络事件）

**定义位置**: `components/bsp/wifi_station/wifi_init.h`

```c
ESP_EVENT_DECLARE_BASE(WIFI_EVENTS);

typedef enum {
    WIFI_CONNECTED_FOR_SNTP = 0,    // WiFi连接成功 → 触发SNTP
    SNTP_SYNC_STARTED,               // SNTP同步开始
    SNTP_SYNC_COMPLETED,             // SNTP同步完成
    SNTP_SYNC_FAILED,                // SNTP同步失败
} wifi_event_id_t;
```

### 📱 APP_EVENTS（应用层事件）

**定义位置**: `main/App/app_event.h`

```c
ESP_EVENT_DECLARE_BASE(APP_EVENTS);

typedef enum {
    APP_MPU6050_DATA_UPDATED = 0,   // MPU6050数据更新
    APP_TIME_INITIALIZED,           // 时间首次同步完成
    APP_MQTT_CONNECTED,             // MQTT连接（预留）
    APP_MQTT_DISCONNECTED,          // MQTT断开（预留）
    APP_MQTT_PUBLISH_SUCCESS,       // MQTT发布成功（预留）
    APP_MQTT_PUBLISH_FAILED,        // MQTT发布失败（预留）
    APP_SENSOR_ERROR,               // 传感器错误（预留）
    APP_NETWORK_ERROR,              // 网络错误（预留）
} app_event_id_t;
```

## 3️⃣ 核心组件详解

### 🔧 事件发布者（Publisher）

**文件**: `main/App/app_event.c`

```c
// 1. 发布MPU6050数据
void app_event_publish_mpu6050_data(float pitch, float roll, float yaw)
{
    app_event_mpu6050_data_t data = {
        .pitch = pitch,
        .roll = roll,
        .yaw = yaw
    };
    
    esp_event_post(APP_EVENTS, APP_MPU6050_DATA_UPDATED, 
                   &data, sizeof(data), portMAX_DELAY);
}

// 2. 发布时间初始化完成
void app_event_publish_time_initialized(void)
{
    esp_event_post(APP_EVENTS, APP_TIME_INITIALIZED, NULL, 0, portMAX_DELAY);
}
```

### 👂 事件订阅者（Subscriber）

**文件**: `main/UI/custom/custom.c`

```c
// 1. 注册事件处理器
void custom_init(lv_ui *ui)
{
    // 创建互斥锁保护共享数据
    mpu6050_data_mutex = xSemaphoreCreateMutex();
    
    // 订阅 MPU6050 数据更新事件
    ESP_ERROR_CHECK(esp_event_handler_instance_register(
        APP_EVENTS,
        APP_MPU6050_DATA_UPDATED,
        &mpu6050_event_handler,  // 回调函数
        NULL,
        NULL));
    
    // 订阅 SNTP 同步完成事件
    ESP_ERROR_CHECK(esp_event_handler_instance_register(
        WIFI_EVENTS,
        SNTP_SYNC_COMPLETED,
        &sntp_sync_event_handler,
        NULL,
        NULL));
    
    // 创建定时器
    lv_timer_create(mpu6050_update_timer_callback, 100, ui);
    lv_timer_create(time_update_timer_callback, 1000, NULL);
}

// 2. MPU6050数据处理回调
static void mpu6050_event_handler(void *event_handler_arg, esp_event_base_t event_base,
                                  int32_t event_id, void *event_data)
{
    if (event_base == APP_EVENTS && event_id == APP_MPU6050_DATA_UPDATED) {
        app_event_mpu6050_data_t *data = (app_event_mpu6050_data_t *)event_data;
        
        // 使用互斥锁保护共享数据
        if (xSemaphoreTake(mpu6050_data_mutex, portMAX_DELAY) == pdTRUE) {
            latest_mpu6050_data.pitch = data->pitch;
            latest_mpu6050_data.roll = data->roll;
            latest_mpu6050_data.yaw = data->yaw;
            xSemaphoreGive(mpu6050_data_mutex);
        }
        
        // 安全更新UI（加锁）
        lvgl_port_lock(0);
        snprintf(buf, sizeof(buf), "%.1f°", data->pitch);
        lv_label_set_text(guider_ui.screen_pitch_data, buf);
        
        snprintf(buf, sizeof(buf), "%.1f°", data->roll);
        lv_label_set_text(guider_ui.screen_roll_data, buf);
        
        snprintf(buf, sizeof(buf), "%.1f°", data->yaw);
        lv_label_set_text(guider_ui.screen_yaw_data, buf);
        lvgl_port_unlock();
    }
}

// 3. SNTP同步完成回调
static void sntp_sync_event_handler(void* arg, esp_event_base_t event_base,
                                    int32_t event_id, void* event_data)
{
    if (event_base == WIFI_EVENTS && event_id == SNTP_SYNC_COMPLETED) {
        ESP_LOGI(TAG, "SNTP sync completed");
        update_time_display();               // 立即更新时间显示
        app_event_publish_time_initialized(); // 广播时间已就绪
    }
}
```

## 4️⃣ 完整事件链条

### 链 1️⃣：MPU6050 数据流

```
定时器(100ms) → 读取传感器 → 发布事件 → 事件总线 → UI更新
     │              │            │           │         │
     ▼              ▼            ▼           ▼         ▼
mpu6050_update_  MPU6050_DMP_  app_event_  APP_EVENTS  mpu6050_event_
_timer_callback  Get_Data()    publish_    分发        handler()
                              mpu6050_                更新label
                              data()
```

### 链 2️⃣：时间同步流

```
WiFi连接 → 触发SNTP → 后台任务同步 → 同步成功 → 发布事件 → 更新UI → 广播时间就绪
    │          │          │           │          │          │          │
    ▼          ▼          ▼           ▼          ▼          ▼          ▼
WIFI_     sntp_event_  sntp_sync_  time_sync_  WIFI_EVENTS  sntp_sync_  app_event_
CONNECTED_  handler()   task()     notification_           event_      publish_
FOR_SNTP              (后台运行)   cb()                     handler()   time_
                                                             ↓         initialized()
                                                        update_time_
                                                        display()
```

**详细流程说明**:

1. **WiFi连接成功** → 发布 `WIFI_CONNECTED_FOR_SNTP` 事件
2. **SNTP模块** 接收事件 → 创建后台任务 `sntp_sync_task`
3. **后台任务** 执行时间同步（非阻塞）
4. **同步成功** → 回调 `time_sync_notification_cb` → 发布 `SNTP_SYNC_COMPLETED`
5. **UI模块** 接收事件 → 更新显示时间
6. **广播** `APP_TIME_INITIALIZED` 给其他模块

## 5️⃣ 线程安全机制

### 互斥锁保护共享数据

```c
// custom.c 中的线程保护

static SemaphoreHandle_t mpu6050_data_mutex = NULL;

// 初始化时创建
void custom_init(lv_ui *ui)
{
    mpu6050_data_mutex = xSemaphoreCreateMutex();
    if (mpu6050_data_mutex == NULL) {
        ESP_LOGE(TAG, "Failed to create mutex");
        return;
    }
}

// 事件处理时加锁
static void mpu6050_event_handler(...)
{
    if (xSemaphoreTake(mpu6050_data_mutex, portMAX_DELAY) == pdTRUE) {
        latest_mpu6050_data.pitch = data->pitch;
        latest_mpu6050_data.roll = data->roll;
        latest_mpu6050_data.yaw = data->yaw;
        xSemaphoreGive(mpu6050_data_mutex);
    }
}

// 外部读取接口
void mpu6050_get_data(mpu6050_data_t *data)
{
    if (xSemaphoreTake(mpu6050_data_mutex, portMAX_DELAY) == pdTRUE) {
        *data = latest_mpu6050_data;  // 安全读取
        xSemaphoreGive(mpu6050_data_mutex);
    }
}
```

### LVGL端口锁保护UI操作

```c
// 所有UI更新操作必须加锁
lvgl_port_lock(0);      // 获取LVGL锁
lv_label_set_text(...); // UI操作
lvgl_port_unlock();     // 释放LVGL锁
```

## 6️⃣ 初始化流程

**文件**: `main/main.c`

```c
void app_main(void)
{
    // 1. 基础初始化
    nvs_flash_init();
    app_event_init();          // 创建默认事件循环
    
    // 2. 硬件初始化
    bsp_i2c_init();
    MPU6050_Init();
    DMP_Init();
    
    // 3. LVGL初始化
    app_lvgl_init();
    
    // 4. UI初始化（在这里注册事件处理器）
    lvgl_port_lock(0);
    setup_ui(&guider_ui);
    custom_init(&guider_ui);   // ← 注册 mpu6050_event_handler
    lvgl_port_unlock();
    
    // 5. 网络/时间初始化
    time_init();               // ← 注册 sntp_event_handler
    wifi_init_sta();           // 连接WiFi，触发事件链
    
    // 6. 主循环（简化）
    while (1)
    {
        vTaskDelay(pdMS_TO_TICKS(1000));
    }
}
```

## 7️⃣ 架构优势

| 特性 | 说明 |
|------|------|
| **解耦** | 数据采集与UI显示完全分离，互不影响 |
| **可扩展** | 新增模块只需订阅事件，无需改动现有代码 |
| **线程安全** | 通过互斥锁和LVGL锁保护共享资源 |
| **异步处理** | SNTP同步在后台任务执行，不阻塞主循环 |
| **预留接口** | MQTT、错误处理等事件已预留，方便后续扩展 |
